# AI Sales Agent 项目开发进度记录

## 项目名称

企业 AI 销售 Agent（AI Sales Agent）

## 项目目标

构建面向企业销售场景的智能 Agent，实现： - 自动理解销售目标 -
自动规划客户调研任务 - 自主调用工具获取企业信息 - 分析客户购买意向 -
输出销售决策建议 - 后续扩展 MCP、RAG、CRM、多 Agent

技术路线： - LangGraph：Agent 工作流编排 - LangChain：LLM 与 Tool
Calling - DeepSeek API：模型推理 - Pydantic：结构化数据校验 -
MCP：企业工具协议 - RAG：知识增强

------------------------------------------------------------------------

# Phase 1：Agent Core（已完成）

完成度：100%

目标： 实现 Planning → Executing → Tool Calling → Review → Result。

## 1. State 状态管理

已实现 SalesAgentState：

保存： - goal - research_plan - messages - candidate_leads - evidence -
status

作用： 维护 Agent 全局上下文。

------------------------------------------------------------------------

## 2. Planning Agent

功能： 根据销售目标自动生成研究计划。

输出： - 行业 - 区域 - 搜索关键词 - 购买信号 - 调研维度

示例信号： - 新建工厂 - 扩产 - 自动化升级 - 招聘机器视觉工程师

------------------------------------------------------------------------

## 3. Executor Agent

功能： 根据计划自主决定下一步动作。

能力： - 理解任务 - 选择工具 - 生成 Tool Calling 请求

------------------------------------------------------------------------

## 4. Tool Calling

已实现 LangGraph ToolNode。

当前工具：

### search_companies

企业搜索

### search_company_news

企业新闻查询

### search_company_jobs

招聘信息查询

实现流程：

AIMessage(tool_calls) → ToolNode → ToolMessage → Agent继续推理

------------------------------------------------------------------------

## 5. LangGraph Workflow

当前流程：

START ↓ Planner ↓ Executor ↓ ToolNode ↓ Executor ↓ Review ↓ END

实现： - StateGraph - Node - Edge - Conditional Edge

------------------------------------------------------------------------

## 6. Review Agent

功能： 根据证据评估客户价值。

输出：

{ company, purchase_intent_score, opportunity_level, evidence,
recommended_action }

例如：

客户： 华东精密汽车零部件有限公司

评分： 0.93

证据： - 新能源零部件基地建设 - 自动化产线 - 招聘机器视觉工程师
